Three Claude Code sessions got the same job: make a motion-graphics video for “I’m Upping My P(Doom)”. P2 adds a request for ambition to P1, and P3 adds a designer persona to P2. Here is what each layer changed in the work and in the result.

The three prompts

P1 Simple, P2 Ambition, P3 Ambition + Persona

Summary

What each layer bought

1 · Quality

Coolness score by axis

Each output scored 0–10 on five axes. Ambition lifted energy most. The persona lifted craft, type and cohesion, and gave up some energy.

Scores are one reviewer’s judgment (Claude Opus 5.5, in a follow-up review session) from sampled frames. The axis starts at 6 because every score sits above it; dots show position, not length.

2 · Effort

What each session spent

Ambition roughly doubled the budget. The persona used about the same time and tokens as ambition, but spent them differently: more turns, more renders, less code per turn.

3 · On screen

What the videos actually do

Measured from the rendered files at 10 frames per second. These numbers describe style, so higher is not always better.

Motion across the song

Motion is the mean pixel change between frames (0–255 scale), averaged over a 5-second window. Shaded bands are the choruses. The simple prompt stays on one moving stage the whole time; the other two cut on nearly every lyric line.

4 · Process

How each session worked

Every tool call on a shared clock, from the moment the prompt arrived. Tall ticks are renders, mid ticks are the agent looking at its own frames, short ticks are everything else.

All numbers

Data table

Read with care

  • One run per prompt. A second run of the same prompt could land somewhere else, so treat the gaps as a signal, not a law.
  • The coolness scores are subjective and came from the same model family that made the videos.
  • The simple-prompt session was interrupted once by the user (“create a new test directory while there is another agent working”), which cost it a few minutes.
  • All three sessions ran at the same time on one machine and shared the CPU and GPU, so wall-clock time is noisy.
  • Session time runs from the prompt to the last logged event. The persona session’s last message was a self-scheduled check-in, not a user message.
